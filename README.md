# 🛒 MERN Stack E-Commerce App

A full-stack E-Commerce web application built with the MERN stack (MongoDB, Express.js, React, Node.js).

The application provides a complete shopping experience, including product browsing, product details, cart management, user authentication, checkout, and order management.

---

## 🌐 Live Demo

🔗 **For live demo:** [click here](https://faizan-fabrics.vercel.app)  

---

## 🚀 Features

### 👤 User Features
- User registration and login
- Secure authentication
- Browse products
- View product details
- Search products
- Filter and sort products
- Add products to cart
- Update product quantities
- Remove products from cart
- Checkout
- Place orders

### 🛍️ Product Features
- Product listing
- Product details
- Product images
- Product pricing
- Product categories
- Search and filtering

### 📦 Order Features
- Create orders
- Store order information
- View order details
- Track order status

### 🔐 Authentication & Security
- User authentication
- Password hashing
- Protected routes
- Authorization
- Secure API endpoints

### 📱 UI & UX
- Responsive design
- Mobile-friendly interface
- Clean and modern UI
- Toast notifications
